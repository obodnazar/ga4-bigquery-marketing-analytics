Method notes
  • Users are distinct counts, so they are pre-aggregated for each filter combination and never summed.
  • Channel attribution is simpler than GA4's last-non-direct model, so totals will not match the GA4 interface exactly.
  • The public sample hides some sources and IDs; those show up as "Unknown (obfuscated)" and in the checks above.
